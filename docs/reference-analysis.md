# Анализ референса

Референс: [sergeyzorin.com](https://www.sergeyzorin.com/).

## Что изучено

- Чёрный фон и строгая моноширинная типографика.
- Крупная ASCII-композиция как основной носитель идентичности.
- Тонкие разделители, функциональная навигация и нижняя status line.
- Контентная иерархия «имя → работы → услуги/процесс → контакт».

## Что перенесено как принцип

Редакционная плотность, терминальный ритм, асимметричная композиция, текстовая интерактивность и приоритет работ над декоративной оболочкой.

## Что сделано оригинально

ASCII-рисунок, палитра dusty coral, сетка, тексты, компоненты, boot sequence, терминальные команды, страницы кейсов и весь исходный код созданы заново. Исходники, изображения и точная композиция референса не копировались. На mobile ASCII заменяется собственной читаемой wordmark-композицией.
