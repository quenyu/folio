# Анализ референса

Референс: [sergeyzorin.com](https://www.sergeyzorin.com/).

## Измеренные принципы

- Центрированный document column шириной 700px.
- JetBrains Mono 15.5px с line-height 27.125px.
- Фон rgb(4, 4, 6), один активный акцент, тонкие разделители и fixed status line.
- Плотная последовательность prompt → ASCII identity → intro → links → separator → selected work.

## Что перенесено

Дисциплина ширины, плотность, моноширинный ритм, status line и принцип глобального акцента.

## Что сделано оригинально

Тексты, данные, ссылки, три case-study, четыре bitmap/dither-конструкции ARTEM / ISAEV, цветовой цикл, разделители, responsive-правила и весь исходный код созданы для портфолио Артёма. Код, личные данные, проектные материалы и точная геометрия букв референса не копировались.
