# Материалы и лицензии

## Проектные изображения

18 WebP-изображений в `public/work/` подготовлены из скриншотов трёх открытых репозиториев пользователя: `techdelo-40-demo`, `poluton-coffee-demo` и `gran-auto`. Они используются только для представления этих работ в портфолио.

## Социальная карточка

`public/og.png` — оригинальная растровая композиция, созданная для этого сайта с помощью генеративного изображения по проектному арт-дирекшну. `public/favicon.png` — оригинальная растровая буква A, созданная локально.

## Шрифт

JetBrains Mono загружается через Next.js Google Fonts. Семейство распространяется по SIL Open Font License 1.1.

## Код

Исходный код референса не использовался. Зависимости проекта перечислены в `package.json` и применяются на условиях собственных open-source лицензий.
