# Контент-стратегия

## Тон

Спокойный, технически точный и деловой. Короткие русские формулировки сочетаются с узнаваемыми английскими терминами интерфейса. Нет агентского пафоса, неподтверждённых суперлативов и вымышленных результатов.

## Доказательства

- Каждая работа содержит production URL и GitHub.
- Подтверждённые Figma-ссылки показаны только у «ПОЛУТОН» и «ГРАНЬ АВТО».
- Метрики тестов взяты из файлов и артефактов соответствующих репозиториев.
- Скриншоты сделаны из реальных сборок проектов.
- Самостоятельный scope честно описывается внутри кейсов без ярлыков, визуально обесценивающих работу.

## Контакты

Telegram и GitHub подтверждены публичным профилем `quenyu`. Email намеренно не придуман; в интерфейсе явно объяснено его отсутствие.

## SEO

Главная оптимизирована под сочетание имени, роли и города; кейсы имеют отдельные title, description, canonical и Open Graph данные. Добавлены Person JSON-LD, sitemap, robots и manifest.
