# Motion system

- Блочный курсор мигает с шаговой функцией; это единственная циклическая анимация.
- ASCII-кнопка по click, Enter или Space последовательно меняет четыре авторские композиции и шесть цветовых тем.
- Hover/focus использует только короткий переход цвета до 180ms.
- Нижняя status line обновляет текущий раздел, время и прогресс прокрутки через requestAnimationFrame.

При prefers-reduced-motion все анимации и переходы сокращаются до 0.01ms, smooth scroll отключается. Важная информация не зависит от движения.
