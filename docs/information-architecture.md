# Информационная архитектура

```text
/
├── Intro / позиционирование
├── Selected work
│   ├── /work/techdelo-40
│   ├── /work/poluton
│   └── /work/gran-auto
├── Services
├── Process
├── About
├── Optional terminal navigation
└── Contact
```

Каждый кейс следует единому повествованию: контекст → аудитория и цели → IA и путь → арт-дирекшн → реальные экраны → responsive/frontend → accessibility/testing → ограничения → следующий проект.

Основная навигация — обычные ссылки и прокрутка. Командная строка только дублирует эти пути, поэтому сайт не требует знания команд.
