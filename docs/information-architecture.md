# Информационная архитектура

```text
/
├── Intro / позиционирование
├── Selected work
│   ├── /work/techdelo-40
│   ├── /work/poluton
│   └── /work/gran-auto
├── Services
├── Process
├── About
└── Contact
```

Каждый кейс следует единому повествованию: контекст → аудитория и цели → IA и путь → арт-дирекшн → реальные экраны → responsive/frontend → accessibility/testing → ограничения → следующий проект.

Главная не использует верхнее меню: разделы идут как один линейный документ, а проекты открываются обычными ссылками. Системная status line показывает текущий раздел и прогресс, но не заменяет навигацию.
