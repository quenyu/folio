# Визуальная система

Подробные токены и правила: `design-system/artem-isaev-portfolio/MASTER.md`.

Основной приём — противопоставление почти чёрного фона, светлого текста и приглушённого кораллового акцента. Один моноширинный IBM Plex Mono объединяет русский текст, интерфейсные подписи и ASCII-art. Тонкие линии заменяют карточки и тени, а большие вертикальные интервалы удерживают редакционный ритм.

Layout построен mobile-first по поведению: на узких экранах все смысловые сетки складываются в одну колонку; на desktop возвращается асимметрия. Изображения имеют заранее заданные размеры и оптимизированы в WebP.
