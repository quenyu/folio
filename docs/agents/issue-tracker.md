# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues for `quenyu/folio`.

## Conventions

- Create, read, comment on, label, and close issues through the GitHub connector or authenticated `gh` CLI.
- Infer the repository from the `origin` remote when working inside the clone.
- Pull requests are not treated as a feature-request or triage surface.
- When an engineering skill says to publish to the issue tracker, create a GitHub issue.
- When an engineering skill says to fetch a ticket, read that GitHub issue together with its comments and labels.
