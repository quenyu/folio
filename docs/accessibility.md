# Accessibility

- Семантические `header`, `nav`, `main`, `section`, `article`, `figure`, `details`, `footer`.
- Skip link ведёт прямо к основному содержимому.
- У всех страниц один логичный `h1`; секции связаны с заголовками через `aria-labelledby`.
- Основные цели имеют размер не менее 44px, а `:focus-visible` создаёт контрастный двухпиксельный outline.
- ASCII-art скрыт от screen reader; доступное имя кнопки — «Артём Исаев» и понятное действие смены композиции.
- Терминальный вывод объявлен через `aria-live`; история и автодополнение доступны с клавиатуры.
- Изображения кейсов имеют содержательные alt-тексты; декоративные превью на главной исключены из accessibility tree.
- Поддержаны `prefers-reduced-motion`, `prefers-contrast` и Windows forced colors.
- Цвета проверены как светлый текст на почти чёрном фоне; коралловый не является единственным индикатором состояния.
