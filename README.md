# Портфолио Артёма Исаева

Тёмное редакционное портфолио web designer + frontend developer из Калуги. Главная страница знакомит с автором и услугами, а три самостоятельных проекта раскрыты как полноценные case studies с настоящими production-скриншотами, ссылками на код и опубликованные сайты.

## Локальный запуск

Требования: Node.js 22.13+ и pnpm 11.

```bash
pnpm install
pnpm dev
```

Сайт откроется на `http://localhost:3000`.

## Проверка

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Или все проверки одной командой: `pnpm qa`.

## Маршруты

- `/` — главная, выбранные работы, услуги, процесс, обо мне и контакты.
- `/work/techdelo-40` — кейс промышленного каталога «ТЕХДЕЛО 40».
- `/work/poluton` — кейс кофейни «ПОЛУТОН».
- `/work/gran-auto` — кейс автосервиса «ГРАНЬ АВТО».

## Стек

Next.js App Router, React 19, TypeScript, Zod, CSS, Vitest и vinext/Sites. Контент проектов валидируется схемами в `app/data.ts`; страницы кейсов генерируются из единой структуры данных.
